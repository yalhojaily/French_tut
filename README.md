# الفرنسية من الصفر · Le français, de zéro à B2

موقع شخصي لتعلّم الفرنسية للناطقين بالعربية: من أسماء الحروف حتى مستوى **B2** (فوق المتوسط)، مع صوت فرنسي أصلي من **ElevenLabs** وتظليل الكلمة لحظة نطقها، وتسجيل صوتك للمقارنة، ومراجعة متباعدة بخوارزمية **FSRS**.

## المنهج

97 وحدة على خمس مراحل، مبنية على الإطار الأوروبي المرجعي (CEFR). المنهج الكامل في [`content/curriculum.json`](content/curriculum.json) ويظهر كخريطة في الصفحة الرئيسية.

| المرحلة | المحتوى | الوحدات | ساعات تقريبية |
|---|---|---|---|
| **0 — الأساس** | الحروف، حروف العلة، الأصوات الصعبة على العربي (p/b، v/f، u/ou، الأنفيات)، قواعد القراءة، الأرقام | 9 | 15–25 |
| **A1** | التعريف بالنفس، أدوات التعريف والجنس، الحاضر، الأسئلة، التسوق والمطعم، المستقبل القريب | 20 | 80–100 |
| **A2** | الماضي المركّب والناقص، الضمائر (COD/COI/y/en)، المقارنة، المستقبل البسيط، الرأي | 20 | 100–120 |
| **B1** | الماضي الأسبق، الشرطي، الـ subjonctif، أدوات الربط، المبني للمجهول، الكتابة والنقاش | 24 | 150–200 |
| **B2** | الشرطي الماضي، الفرضيات، الكلام المنقول، الإبراز، المقال الحِجاجي، الفرنسية المحكية | 24 | 180–250 |

### بنية كل وحدة

1. **حوار** مسموع بصوتين (عادي وبطيء) مع تظليل الكلمات، والترجمة مخفية افتراضياً
2. **المحتوى الأساسي** (في الوحدة 0.1: الحروف والعلامات)
3. **تمرين استماع** (اختيار ما تسمعه)
4. **إملاء** مع لوحة الحروف ذات العلامات
5. **ترديد (shadowing)**: تسمع، تسجّل، تقارن
6. **بطاقات** تدخل المراجعة المتباعدة

**الجاهز الآن:** المرحلة 0 كاملة (9 وحدات): الحروف، والأصوات، وقراءة التراكيب، والوصل، والأرقام من 0 إلى المليون. ومن A1 سبع وحدات (A1.1–A1.7): التحية والتعريف بالنفس، أدوات التعريف والجنس، être، الأسئلة، avoir وأدوات الملكية، العائلة، ووصف الأشخاص.

## التصميم

دفتر رسم مائي لباريس: لكل مرحلة مكان ولوحة ولون.

| المرحلة | المكان | اللون |
|---|---|---|
| 0 | المقهى (Au café) | أحمر الجيرانيوم |
| A1 | المخبز (À la boulangerie) | أصفر دوّار الشمس |
| A2 | ضفاف السين (Sur les quais) | أخضر السين |
| B1 | مونمارتر (À Montmartre) | بنفسجي الغروب |
| B2 | البرج (Au pied de la tour) | أزرق السماء |

الصفحة الرئيسية لوحة بانورامية، ثم كل مرحلة صفحتان متقابلتان: لوحة المكان، ووحداتها كبطاقات بريدية عليها طابع برقم الوحدة. وفي صفحة الوحدة تظهر لوحة مرحلتها في الأعلى، ويتلوّن كل شيء بلونها.

اللوحات مرسومة بالكود في [`art/paint.py`](art/paint.py) (أشكال SVG مع مرشّحات تحاكي الألوان المائية)، ثم تُحوَّل إلى صور WebP في `web/public/art/`. لإعادة رسمها بعد تعديل السكربت:

```bash
python3 art/paint.py            # كل اللوحات
python3 art/paint.py cafe       # لوحة واحدة
```

الخطوط مضمّنة في الموقع (لا تُحمَّل من Google): Caveat للعناوين الفرنسية، Literata للنص الفرنسي، El Messiri لعناوين العربية، Readex Pro لنصها.

## التشغيل

```bash
cd web
npm install
npm run dev        # افتح الرابط الذي يظهر
```

بدون توليد الصوت، يعمل الموقع بصوت المتصفح الفرنسي كبديل مؤقت.

## توليد الصوت بـ ElevenLabs

السكربت مكتوب ببايثون دون أي مكتبة خارجية.

```bash
cp .env.example .env                      # ضع مفتاحك في ELEVENLABS_API_KEY
python tools/generate_audio.py voices     # اعرض الأصوات في حسابك
```

1. اختر الأصوات:
   - **الخطة المجانية:** تعمل الأصوات الجاهزة (premade) فقط عبر الـ API. اعرضها بـ `python tools/generate_audio.py voices --premade`.
   - **الخطط المدفوعة:** يمكنك إضافة أصوات فرنسية أصلية من Voice Library إلى حسابك.
   - جرّب أي صوت قبل اعتماده (نحو 90 حرفاً): `python tools/generate_audio.py sample VOICE_ID`
2. ضع معرّفاتها في [`content/voices.json`](content/voices.json).
3. ولّد الصوت:

```bash
python tools/generate_audio.py build --dry-run   # ماذا سيُرسل وكم حرفاً
python tools/generate_audio.py build             # التوليد الفعلي
```

ما يفعله السكربت:

- يجمع كل عنصر فيه `id` و `say` من ملفات الوحدات، ويولّد نسخة بطيئة لكل عنصر عليه `"slow": true`.
- يستخدم نقطة `with-timestamps` ليحفظ توقيت كل حرف، فيظلّل الموقع الكلمة لحظة نطقها.
- **لا يعيد توليد شيء موجود**: اسم الملف بصمة للنص والصوت والإعدادات. العناصر المتطابقة تتشارك ملفاً واحداً. الوحدة 0.1 كلها نحو 1,400 حرف.
- يحفظ الملفات في `web/public/audio/` والفهرس في `manifest.json`. المفتاح لا يصل إلى الموقع أبداً.
- `--prune` يحذف الملفات التي لم تعد مستخدمة بعد تعديل النصوص.

> **النطق الفرنسي:** الإعداد الحالي يستخدم `eleven_flash_v2_5` مع `"language_code": "fr"` لفرض الفرنسية، ويرسل سياقاً فرنسياً غير منطوق قبل الحروف والكلمات القصيرة. بدون ذلك تقرأ الأصوات الإنجليزية الحروف المنفردة بالإنجليزية. والأفضل دائماً صوت فرنسي أصلي من Voice Library (يحتاج خطة مدفوعة).
>
> وفي الموقع زر «الصوت» أعلى الصفحة للتبديل إلى صوت المتصفح الفرنسي في أي وقت.

> مفتاح الـ API يحتاج صلاحية **Text to Speech**، وصلاحية **Voices: Read** لأمر `voices`.

> **استمع لملفات الحروف المنفردة بنفسك.** محركات TTS قد تخطئ في مقطع قصير جداً مثل «u» أو «e». إن أخطأ صوت، غيّر نص `say` (مثلاً اكتب الحرف كما يُنطق) وأعد التوليد.

## التوليد التلقائي على GitHub

بعد حفظ المفتاح مرة واحدة في **Settings ← Secrets and variables ← Actions** باسم `ELEVENLABS_API_KEY`، يولّد GitHub الصوت تلقائياً مع كل دفع إلى `main`:

1. يفحص المحتوى (`check_content.py`).
2. يولّد ما هو جديد فقط، ويحذف الملفات غير المستخدمة.
3. يرفع ملفات الصوت في commit باسم «Generate audio [automated]».
4. يبني الموقع وينشره.

للحماية: إن تجاوز التوليد 15,000 حرف في مرة واحدة (مثلاً بعد تغيير الأصوات) يتوقف ولا يُنشر، فتولّده يدوياً عن قصد. وبعد كل تحديث تلقائي اسحب بـ `git pull` قبل أي تعديل محلي.

## إضافة وحدة جديدة

أنشئ `content/units/<id>.json` بنفس معرّف الوحدة في المنهج (مثل `u0-02.json`). تظهر الوحدة تلقائياً كجاهزة في الخريطة. أنواع الأقسام المتاحة الآن:

| `type` | الاستخدام |
|---|---|
| `dialogue` | حوار بمتحدثين، لكل متحدث صوت |
| `letters` | شبكة حروف أو أصوات مع مثال لكل منها |
| `accents` | قائمة مفاهيم مع أمثلة مسموعة |
| `listen_choice` | تسمع وتختار |
| `spelling` | تسمع وتكتب |
| `shadowing` | تسمع وتسجّل وتقارن |
| `flashcards` | بطاقات للمراجعة المتباعدة |
| `vocab` | مفردات في مجموعات، لكل منها صوت ومعنى وملاحظة |
| `grammar` | جداول قواعد (تصريف فعل مثلاً) ونقاط شرح |
| `fill_choice` | اختر الكلمة الناقصة، ثم تُسمع الجملة كاملة |

كل سطر حوار وكل جملة ترديد يحتاج حقل `gloss` (ترجمة كلمة بكلمة)، وأجزاؤه يجب أن تكوّن الجملة حرفاً بحرف. الأمر `python tools/check_content.py` يفحص ذلك، ويعمل تلقائياً قبل كل نشر، فلا تُنشر وحدة ناقصة.

الأنواع معرّفة في [`web/src/types.ts`](web/src/types.ts). كل عنصر مسموع يحتاج `id` فريداً داخل الوحدة و `say` (النص الفرنسي المنطوق).

## البنية

```
content/
  curriculum.json        المنهج الكامل (97 وحدة)
  units/u0-01.json       محتوى الوحدات الجاهزة
  voices.json            إعدادات ElevenLabs والأصوات
tools/
  generate_audio.py      توليد الصوت والتوقيتات
web/                     الموقع (TypeScript + Vite)
  src/views/             الخريطة، الوحدة، المراجعة
  src/sections/          قسم لكل نوع تمرين
  src/audio.ts           تشغيل الصوت والتظليل وصوت المتصفح الاحتياطي
  src/srs.ts             المراجعة المتباعدة (ts-fsrs)
  src/scenes.ts          مكان كل مرحلة ولوحتها ولونها
  public/audio/          الصوت المولّد
  public/art/            اللوحات المائية
art/paint.py             رسم اللوحات
```

التقدم والبطاقات محفوظة في متصفحك (localStorage). التسجيلات الصوتية لا تُحفظ ولا تُرفع.

## النشر على GitHub Pages

يوجد ملف نشر تلقائي في `.github/workflows/deploy.yml`. فعّله مرة واحدة من **Settings ← Pages ← Source: GitHub Actions**، وبعدها كل دفع إلى `main` ينشر الموقع. ارفع ملفات الصوت المولّدة مع الكود حتى تظهر في النسخة المنشورة.
